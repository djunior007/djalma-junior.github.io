## Publicar gratuitamente no GitHub Pages
1. Entre ou crie uma conta em https://github.com/
2. Crie um repositório público chamado `SEUUSUARIO.github.io` (substitua pelo seu usuário GitHub).
3. Envie o arquivo `index.html` para a raiz do repositório.
4. Em Settings → Pages, configure a publicação pela branch `main` e pasta `/(root)`, caso solicitado.
5. Depois que a publicação concluir, o site ficará no endereço `https://SEUUSUARIO.github.io/`.

O site está pronto como arquivo, mas não é possível criar um endereço público real sem publicar numa plataforma.
